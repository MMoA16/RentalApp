# Rental Manager Website

A simple website for managing rental business records without using a database.

## Tech stack
- Plain HTML, CSS, and JavaScript
- Browser localStorage for saving data
- `serve` for running the site locally

## Features
- Track up to 30 rental houses
- Add, edit, and delete property records
- Record monthly rent, deposit, balance, current bill, and water bill
- View totals for rent, deposit, balance, and bills
- Data saved in the browser locally

## Setup
1. Open the project folder:

```bash
cd "Rental App"
```

2. Install dependencies:

```bash
npm install
```

3. Run the website:

```bash
npm start
```

4. Open the browser at:

```text
http://localhost:3000
```

## Notes
- No database is required.
- Data is stored in the browser using localStorage.
- If you want cloud sync or a login system later, I can add that next.
